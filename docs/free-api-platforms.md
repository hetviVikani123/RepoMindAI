# Free API Platforms for RepoMind AI

## Recommended free-first stack

- LLM/API reasoning: Google AI Studio Gemini API
- Vector store: Qdrant Cloud free tier
- Graph database: Neo4j AuraDB Free
- Embeddings: Hugging Face free inference options or local fallback
- Repository access: GitHub personal access token

## Other practical free or freemium options

- Groq for fast inference on supported open models, depending on current developer access programs
- OpenRouter for routing to available community/free models, depending on current catalog availability
- Hugging Face for hosted inference endpoints and community models
- Google AI Studio for Gemini free tier access

## Notes

- Free tiers change often.
- Some providers require account creation even when the usage tier is free.
- For production stability, keep the local hash/vector fallback path in place.
